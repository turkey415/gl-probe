Change mode

Router: the WAN port is the uplink, the router hands out 192.168.8.x and this page is at https://192.168.8.1:8088. Access point: the WAN port joins the LAN, the router stops handing out addresses and takes one from the network on WAN; this page moves to that address (the router's screen shows it). The change uses GL.iNet's own Network Mode call and keeps every setting. Wi-Fi drops for about a minute. The side switch and a 3 s hold on the screen's Mode page do the same.

Port finder

off

Bounces the WAN link (down 1.5 s, then up for 2 s once it's back: a flash every 6 to 7 s) so the switch port's LED blinks. Walk the switch and look for it. The router's own network drops while it runs; the tester keeps what it knew about the port.

The router's screen live, every 2 s

Who draws it

GL Probe's pages: Summary, Switch, Port, Layer 2, Ping, Mode. Tap or swipe for the next page; hold 1.5 s to hand the screen to GL.iNet's own program (hold 3 s on the Mode page to change the network mode). The tester keeps running with either.
